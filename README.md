# Beginner3

スマホで動くシンプルなToDo（タスク管理）アプリです。

## 使い方

1. `index.html` をスマホのブラウザで開く
2. 入力欄にやることを書いて「＋」ボタンで追加
3. 完了したタスクはチェックボックスにチェック
4. いらなくなったタスクは「✕」ボタンで削除

タスクはブラウザの localStorage に保存されるので、ページを閉じても消えません（同じブラウザ・同じ端末で開いた場合のみ）。

## 動かし方（GitHub Pagesで公開する場合）

1. GitHubのリポジトリ設定 → Pages
2. Branch を `main`（またはこの機能を反映したブランチ）、フォルダを `/ (root)` に設定
3. しばらくすると `https://<ユーザー名>.github.io/<リポジトリ名>/` でアクセスできるようになる
4. そのURLをスマホのブラウザで開けばOK
